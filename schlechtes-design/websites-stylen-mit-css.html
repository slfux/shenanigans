Websites stylen mit CSS

Was ist CSS?

CSS steht für Cascading Style Sheets und wird verwendet um das Erscheinungsbild von Webseiten zu gestalten. Farben Schriften Abstände Größen und Layouts können mit CSS definiert werden.

Warum CSS verwenden?

Ohne CSS erscheinen Webseiten meist sehr schlicht. Durch CSS lassen sich Inhalte visuell strukturieren und hervorheben.

Eigenschaften im Überblick

color
Legt die Textfarbe fest.
background-color
Legt die Hintergrundfarbe fest.
font-size
Bestimmt die Schriftgröße.
margin
Definiert Außenabstände.
padding
Definiert Innenabstände.

CSS-Beispiel


h1 {
    color: blue;
    font-size: 32px;
}

p {
    color: red;
}
