Funktionalität mittels JavaScript

Was ist JavaScript?

JavaScript ermöglicht die Umsetzung interaktiver Funktionen innerhalb von Webseiten. Inhalte können verändert, Formulare überprüft und Benutzereingaben verarbeitet werden.
